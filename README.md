# Poke-ko v1.0.1 — KD / KG 비교판

설치 페이지: https://zila81.github.io/Poke-ko/

언어 순서:

`ES → EN → FR → DE → IT → PT → KD → KG`

- KD = 한국어 + DotumChe
- KG = 한국어 + GulimChe
- KD/KG 모두 동일한 한국어 UI 및 151마리 한국어 이름
- 작은 글씨 11px / 일반 12px / 큰 글씨 14px
- 기존 언어 번호 0~5 유지, KD=6, KG=7
- 웹 설치기의 원본 JavaScript/Web Serial/sprite 전송 기능 보존

실기에서 KD와 KG를 전환하면서 같은 화면을 비교한 뒤 최종 폰트를 선택할 수 있습니다.
