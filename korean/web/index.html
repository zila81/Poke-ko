🎮 TamaPoke 한국어판

Waveshare ESP32-S3-Touch-AMOLED-1.75 전용

준비물: PC + Chrome/Edge, USB 데이터 케이블, microSD 카드.

이 브라우저는 USB 설치 기능을 지원하지 않습니다. PC Chrome/Edge에서 열어주세요.

1한국어 펌웨어 설치

기기를 USB로 연결하고 아래 버튼을 누른 뒤 ESP32-S3 포트를 선택하세요.

PC Chrome/Edge가 필요합니다.HTTPS에서만 사용할 수 있습니다.

기존 세이브 유지: 설치 창에서 Erase/지우기를 선택하지 마세요. 완전 초기화를 원할 때만 지우기를 사용하세요.

2포켓몬 그림 데이터 설치

1단계 설치 창을 닫고 microSD가 기기에 꽂혀 있는지 확인하세요. 아래 버튼 하나로 연결부터 전송까지 진행합니다.




3재시작
완료 후 PWR 버튼으로 기기를 재시작하세요.


✅ UI 한국어 + 1세대 151마리 한국어 이름이 적용됩니다.
